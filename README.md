# 수능 감독관

2027학년도 수능 시험실에서 부정행위자를 찾아내는 도트 텍스트 게임 (테스트 버전).

## 이미지 중심 구조

- 단서는 글이 아니라 **확대 도트 그림**에 있다. 수험생을 고르고 "가까이 보기"나 "본인 확인"을 하면 그 순간의 확대 그림(160×120)이 나온다.
- 그림에 그려지는 것: 얼굴과 귀, 안경 테 두께, 셔츠 단추와 스티커, 손목시계 바늘, 문제지 풀이 흔적, OMR 마킹, 사인펜, 수험표 사진, 꺼낸 소지품.
- 확대 그림은 수험생별 **수첩(스냅숏 앨범)**에 쌓인다. 오전과 오후 그림을 넘겨 보며 비교한다.
- 글은 시각·이름 캡션, 이번 교시에 앞에서 보인 짧은 장면, 처리 결정 때만 쓴다.
- 그림 상태는 `game.js`의 `makeView()`가 만들고 `pixel.js`의 `drawCloseup()`이 그린다.

## 현실을 반영한 부분

- **2027 수능 감독 절차**: 08:10~08:40 입실 점검(본인 확인, 소매·옷깃·단추 스티커, 안경 벗겨 검사, 휴대 물품), 08:25 위급재난문자, 2~4교시 본인 확인, 3교시 전 휴대 물품 재점검, 의심되면 교시 후 점검
- **30분은 모자란다**: 12명을 전부 꼼꼼히 볼 수 없다. 못 본 수험생은 부감독관이 스티커만 붙인다.
- **교시 흐름**: 교시 중에 본인 확인(2교시부터)과 순회를 한다. 의심 표시한 수험생이 있을 때만 쉬는 시간 정밀 점검 단계가 열리고, 없으면 바로 다음 교시로 넘어간다.
- **계획형 1~2명 (매 판)**: 절차를 알고 오래 준비해 온 사람. 2026년 11월 보도된 장비 경향을 반영했다.
  - 스마트안경: 오전 검사용 안경을 쓰고 와서 점심에 바꿔 씀
  - 단추형 초소형 카메라: 스티커가 "저절로" 자꾸 떨어짐
  - 사인펜 위장 카메라: 지급 펜과 바꿔치기
  - 쌀알 크기 이어폰: 금속탐지기로 50%만 잡힘, 듣기평가 때 한쪽 귀를 막음
  - 몸에 붙인 진동 수신기: 답 번호를 진동 횟수로 받음
  - 아날로그로 위장한 스마트워치: 소매 검사에서 "허용되는 시계"로 통과
  - 대리 응시
- **실수형 0~1명**: 휴대폰, 전자시계, 이어폰 케이스, 종료령 후 답안 작성, 4교시 응시 방법 위반
- **무고한 수험생의 습관**이 계획형 징후와 겹친다: 귀 만지기, 책상 두드리기, 시계 보기, 사인펜 세워 들기, 듣기 때 귀 막기 등
- 장비를 만들거나 숨기는 방법은 다루지 않는다. 감독관에게 보이는 징후만 쓴다.

## 실행

```bash
npm run serve        # http://localhost:8000
npm test             # 게임 규칙 테스트
npm run bundle       # dist/suneung.html 한 파일로 묶기 (글꼴 서브셋: pip install fonttools brotli)
```

## 구조

| 파일 | 역할 |
|---|---|
| `src/data.js` | 게임 내용: 시간표, 실수형·계획형·습관, 관찰 문장, 반응 대사, 외모 부품 |
| `src/game.js` | 규칙: 판 생성, 입실 점검, 본인 확인, 순회, 교시 후 점검, 종료령, 채점 |
| `src/pixel.js` | 도트 시험실 12석 (이미지 파일 없음) |
| `src/card.js` | 결과 공유 카드 |
| `src/main.js` | 화면 연결 |
| `fonts/` | 갈무리11 도트 글꼴 (SIL OFL 1.1, `Galmuri-LICENSE.txt`) |

상황을 늘릴 때는 `src/data.js`만 고치고 `npm test`로 확인한다.
