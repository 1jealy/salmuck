# 수능 감독관

수험생 다섯 명 중 부정행위자를 찾아내는 텍스트 추리 웹게임 (테스트 버전).

- 교시마다 행동 2번: **가까이 관찰** 또는 **말 걸기**
- **소지품 검사**는 시험 전체에서 1번
- 말을 걸면 민원 1건, 무고한 수험생을 검사하면 민원 2건
- 4교시가 끝나면 부정행위자를 지목하고 1~9등급으로 채점
- **시험실 번호**(4자리)가 같으면 같은 판이 나와서 친구와 대결 가능
- 결과 카드 이미지 생성 (공유용)

## 실행

빌드 과정 없이 정적 파일만으로 돌아갑니다. ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
npm run serve        # http://localhost:8000
npm test             # 게임 규칙 테스트
npm run bundle       # dist/suneung.html 한 파일로 묶기
```

GitHub Pages, Vercel, Netlify 등에 폴더째 올리면 그대로 배포됩니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/data.js` | **게임 내용**. 부정행위, 헷갈리는 행동, 성격별 대사, 소지품, 분위기 사건, 도트 외모 부품 |
| `src/game.js` | 게임 규칙. 판 생성(조각 조합), 관찰·질문·검사, 교시 진행, 채점. 화면과 분리된 순수 로직 |
| `src/pixel.js` | 도트 시험실과 수험생을 캔버스에 직접 그림 (이미지 파일 없음) |
| `src/card.js` | 결과 공유 카드(1080×1350) 생성 |
| `src/main.js` | 버튼, 캔버스 터치, 감독 일지, 결과 화면 연결 |
| `test/` | 규칙 테스트 (`node --test`) |
| `scripts/bundle.mjs` | 모든 파일을 HTML 한 장으로 묶기 |

## 상황 추가하는 법

`src/data.js`만 고치면 됩니다. `{n}`은 그 수험생 번호, `{m}`은 짝(공범) 번호로 바뀝니다.

- **새 부정행위**: `CHEATS`에 항목 추가
  - `public`: 교시 시작 때 누구나 보는 단서 (2개 이상)
  - `close`: 가까이 관찰했을 때 나오는 단서
  - `guiltyLines`: 말 걸었을 때 둘러대는 대사
  - `inspect`: 소지품 검사 결과 (`found: false`면 검사로는 못 잡음)
  - `periods`: 특정 교시에만 단서가 나올 때 (0=1교시)
  - `atEnd: true`: 단서가 교시 끝(종료령)에 나옴
- **새 헷갈리는 행동(무고)**: `HERRINGS`에 같은 형식으로 추가
- **새 성격**: `TRAITS`에 대사 목록 추가

추가한 뒤 `npm test`로 빈 자리표시나 단서 부족이 없는지 확인하세요.

## 내용 원칙

- 부정행위는 수능 유의사항에 공개된 금지 행위와 코믹한 설정만 다룹니다. 실제 수법을 안내하지 않습니다.
- 공식 기관 로고나 문서 형식을 흉내 내지 않습니다.
