# 수능 감독관

2027학년도 수능 시험실에서 부정행위자를 찾아내는 도트 텍스트 게임 (테스트 버전).

## 현실을 반영한 부분

- **2027 수능 감독 절차**: 08:10~08:40 입실 점검(본인 확인, 소매·옷깃·단추 스티커, 안경 벗겨 검사, 휴대 물품), 08:25 위급재난문자, 2~4교시 본인 확인, 3교시 전 휴대 물품 재점검, 의심되면 교시 후 점검
- **30분은 모자란다**: 12명을 전부 꼼꼼히 볼 수 없다. 못 본 수험생은 부감독관이 스티커만 붙인다.
- **실수형(대부분)**: 휴대폰(켜짐/꺼짐), 전자시계, 무선 이어폰 케이스, 종료령 후 답안 작성, 4교시 응시 방법 위반. 시험 전에 나오면 제출로 끝, 시험 중에 나오면 부정행위.
- **계획형(65% 확률로 1명)**: 절차를 알고 준비해 온 사람. 스마트안경(오전 점검용 안경을 쓰고 와서 점심에 바꿈), 단추형 카메라(스티커가 "저절로" 자꾸 떨어짐), 대리 응시. 감독관 쪽에서 보이는 징후만 다룬다.
- **무고한 수험생의 습관**이 계획형 징후와 겹친다: 안경 고쳐 쓰기, 스티커 긁기, 풀이 흔적 없는 암산 등.

## 실행

```bash
npm run serve        # http://localhost:8000
npm test             # 게임 규칙 테스트
npm run bundle       # dist/suneung.html 한 파일로 묶기 (글꼴 서브셋: pip install fonttools brotli)
```

## 구조

| 파일 | 역할 |
|---|---|
| `src/data.js` | 게임 내용: 시간표, 실수형·계획형·습관, 관찰 문장, 반응 대사, 외모 부품 |
| `src/game.js` | 규칙: 판 생성, 입실 점검, 본인 확인, 순회, 교시 후 점검, 종료령, 채점 |
| `src/pixel.js` | 도트 시험실 12석 (이미지 파일 없음) |
| `src/card.js` | 결과 공유 카드 |
| `src/main.js` | 화면 연결 |
| `fonts/` | 갈무리11 도트 글꼴 (SIL OFL 1.1, `Galmuri-LICENSE.txt`) |

상황을 늘릴 때는 `src/data.js`만 고치고 `npm test`로 확인한다.
